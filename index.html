Patch cable

The firmware clock (PGM 3 set, PGM 4 show, op-code F06) counts the pulses on input 4.

A cable from an output to an input, so a program can read back what it wrote.

Sound

Silent.

The piezo buzzer sounds while its output is on. PicoRAM 2090 notes: op-code 50D, then octave and note, each given as 0xx (literal) or 3Fx (from register x).

Inside

Click a line to edit that instruction; the program counter line is highlighted.

Keys

The whole machine can be driven from the PC keyboard: 0–9 A–F hex · H HALT · N/Enter/Space NEXT · R RUN · S/T STEP · K BKP · G REG · P PGM · X/Backspace C/CE · Esc Reset · , key G · . key H. So H N 0 0 R starts a program.

Inputs: click an input jack to plug in a high level; click the 1 Hz jack (or use the Patch cable setting) to connect the clock to input 4.

Enter a program: HALT NEXT 0 0, then three hex digits and NEXT per instruction. Start it: HALT NEXT 0 0 RUN. Built in: PGM 7 Nim, PGM 5 clear memory, PGM 6 fill with NOP, PGM 3/4 set/show clock, PGM 0 self test.
